# Yor / Ayrin — Portfolio

This project is the focused portfolio surface for Ayush Roy: selected work, proof of craft, experience, and a direct contact path.

The broader experiments, playable games, field notes, and media archive live in the separate [Yorayriniwnl.in hub](https://yorayriniwnl.in).

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run build
npm run lint
npm run typecheck
```

There is intentionally no contact form, dashboard, API route, or game runtime in
this repository. Those belong to the separate hub project.

## Stack

Next.js, React, TypeScript, and CSS. The home page is intentionally the only portfolio route; supporting legacy route trees are no longer part of this product surface.
